# 实时页面验证与延迟诊断

[返回 README](../README.md) · [正式运行](formal_demo.md) · [同步协议](realtime_development.md) · [vLLM](vllm.md)

以下步骤使用正式页面与公开启动脚本。模型和环境准备见[环境说明](environment.md)。

## 启动与首次验证

从项目根目录按网络环境选一个入口。例如，计算节点无外网、登录节点可联网时：

```bash
mkdir -p outs
sbatch --partition=GPU_PARTITION scripts/slurm/serve_login_relay.sh
```

计算节点能联网则使用 `serve_direct.sh`；普通 GPU 机器用 `bash scripts/run/serve_share.sh`。配置 `.env.local` 后，等待日志的 `PUBLIC_URL`，进入“同声传译”。两页使用一个端口，默认自动托管 vLLM。

1. 选择示例，点击“播放并实时测试示例”。应能听到完整声音，原文独立出现，译文随后跟进。默认播放不为等待字幕暂停。
2. 已有字幕应保留，新内容追加或在尾部修订，不应每次清空后从头逐字输出。最终完整翻译仍可能改写较早内容。
3. 音频结束后等待“处理完成，最终结果已同步”。原文和译文最终版本应一致；结束输入不等于翻译已完成。
4. 手动选择输入语言，开始录音。讲话后安静等待 2.5 秒，应自动停止并补齐结果；短暂停顿不固定切成多段。
5. 将静音等待改为 4 秒，或关闭自动结束后手动停止，再重复一次。初始等待、取消和下一次录音均应正常。
6. 实时会话未结束时到文件页提交，应得到任务占用提示；结束或取消后可继续使用文件页。

## 展示样本与观察方法

默认 10 条样本约 15–27 秒，包含中→英/日、英→中/法、法→中、德→英、西→中、意→德、葡→西、荷→英。精确时长与文件名以清单为准，来源见[说明](../data/test_samples/SOURCES.md)。

先验证中英互译，再测试其他方向。固定语言、样本、播放节奏、网络入口及参数，重复两次；首次请求可能包含预热。前导停顿与 ASR 所需右侧上下文也计入“开播→首条字幕”，不能全部算作网页刷新耗时。

音量只作用于浏览器输出，静音不会阻止识别。默认“实时播放”继续完整播放；“网络适配”仅在上传积压时暂停，会改变声音时钟，不适合直接比较两种模式的字幕相对播放延迟。

## ASR 与翻译独立运行

原文先更新、译文稍后完成。翻译慢时不应暂停声音，或等译文后才发布 ASR。前端优先消费轻量原文消息，译文使用独立快照；瞬时 ASR 版本不必逐个翻译，但最终版本必须处理。

`REALTIME_CUDA_STREAMS=1` 在 Demo 进程内给 ASR 请求高优先级计算流。vLLM 是另一个进程，这不保证跨进程 GPU 抢占；调大翻译批次或上下文时，应同时检查原文延迟。

## 延迟诊断

展开页面“延迟诊断”，重点比较：

| 指标 | 含义 |
| --- | --- |
| 开播/采集→首条原文可见 | 浏览器收到并显示 ASR 的等待 |
| 首个译文片段 / 首份完整译文可见 | 提前显示候选与完整翻译完成的区别 |
| 后端收到首块→产生原文/译文 | 排除建连前等待，仍含声音上下文与前处理 |
| 上传确认 RTT / HTTP 查询 RTT | 网络往返及 HTTP 回退开销 |
| 结果产生→页面可见 | 经过校时的交付延迟估计，不是精确单向网络测量 |
| 最大未确认音频 / 自动暂缓次数 | 上传积压和网络适配暂停 |
| 输入结束原因 | 麦克风静音自动结束或连接/上传错误 |

原文和译文同时变慢，先比较上传积压、网络 RTT 和原文产生耗时；只有译文变慢时，查看输入长度、vLLM 生成速度及翻译排队。诊断区切换为 HTTP 可对照长连接路径；自动模式在 WebSocket 建立失败时回退 HTTP。

当前仍会重译累计原文，长文本需要更多生成时间。字幕投影和 vLLM 不能保证长会话的固定延迟。输入/输出达到上限会明确报错，不把截断结果标成最终文本。

## 配置项与同步规则

常用配置见[配置表](configuration.md#实时-asr-与级联)。服务配置修改后重启作业；自动停止开关与静音等待则在页面上、录音前调整。

- `REALTIME_ASR_LOOKAHEAD=3`：较低 lookahead 可减少等待，也可能影响准确性，需固定样本对照。
- `REALTIME_TRANSLATION_INTERVAL=0.6`：文本翻译调度间隔，不切音频，也不等于固定端到端时延。
- `REALTIME_MAX_SECONDS=120`：会话输入时长上限，与静音自动停止不同。
- `REALTIME_MT_STREAMING=1`：生成中发布候选；设为 0 可对照只显示完整结果的方式。

停止时先补发尾部并等待上传确认，再结束 ASR 输入；随后等待翻译检查点和最终版本。主字幕读取 `translation_display*`，不直接用每轮从空串生成的 `translation_draft` 清空字幕。字段与排序规则见[同步协议](realtime_development.md)。

## 无 GPU 界面预览

```bash
bash scripts/run/serve_local.sh --demo-mode
```

打开 `http://127.0.0.1:7860`，检查录音、播放、自动停止和布局。实时字幕明确标注 MOCK，不加载 GPU 模型，不能验证真实识别/翻译质量或速度。外部设备录音仍需正式网络入口的 HTTPS。
